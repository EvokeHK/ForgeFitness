# Forge Fitness

A modern, responsive gym and fitness website built with Django. The project focuses on creating a premium user experience while following clean frontend and backend development practices.

---

## Tech Stack

- Python
- Django
- HTML5
- CSS3
- JavaScript

---

## About

Forge Fitness is a full-stack Django web application that simulates the website of a premium fitness center.

The goal of this project is not only to build a visually appealing website but also to learn professional web development practices including responsive design, reusable templates, Git workflows, and Django architecture.

---

## Features

- Modern landing page
- Responsive design
- Clean and reusable components
- Django template system
- Organized project structure
